# Kepler WIS Detection

Scientific code associated with the detection pipeline presented in:

**Oryna Ivashtenko and Barak Zackay (2025)**, *An Independent Search for Small Long-period Planets in Kepler Data. I. Detection Pipeline*, **The Astronomical Journal**, 170(6).  
https://doi.org/10.3847/1538-3881/adfc50

## About this repository

This repository contains code associated with the research described in the paper above. For the scientific motivation, methodology, and interpretation, please refer to the publication.
